现状主要问题

  • 标题栏拥挤：标题、计数、原生灰色「IM」按钮挤在一行，按钮风格与主题不符
  • 详情弹窗：12 行信息拼成一段纯文本，签名很长难以阅读，也无法单独复制
  • IM 页：消息是直角色块，文件消息只有文字；加载 / 断线时整屏遮挡历史
  • 入口分散：服务地址、文件管理网页、权限状态没有统一位置
  • 系统开关：Switch 文案「系统」含义不明确，也看不到各类数量

实现建议（确认后再改代码）

  • MainActivity 改为宿主 + 3 个页面，用 FrameLayout 切换 View 显示 / 隐藏（不引入 Fragment），底部导航用自定义 LinearLayout 实现
  • WebImActivity 内容迁到「聊天」页，消息区改用 RecyclerView + 两种 ViewType（文字 / 文件）
  • 底部弹层用系统 Dialog + Gravity.BOTTOM + 上滑动画实现；筛选芯片用 TextView + selector 背景，不引入 Material 库
  • 圆角、描边统一放到 res/drawable 的 shape 中；新增 values-night/colors.xml 支持深色模式
  • 图标全部写成 res/drawable 的 VectorDrawable；复制用系统 ClipboardManager，分享地址用 Intent.ACTION_SEND
  • 不新增任何第三方依赖：只用现有的 androidx core / activity / recyclerview

设计规范

  • 圆角：卡片 18dp、按钮 12dp、芯片 / 输入框全圆角
  • 间距：页面左右 12–16dp，列表行高 ≥ 64dp
  • 字号：大标题 20sp、列表名 15sp、辅助 12sp、包名等宽 12sp
